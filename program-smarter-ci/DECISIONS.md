# Decisions
- SQLite is authoritative during a workout; network is never on the critical logging path.
- Progression is deterministic rather than LLM-driven.
- Exercise art is original local vector illustration rather than copyrighted photography.
- Time Compression only removes low-priority volume first and never changes load merely to fit time.
- Imported unknown exercises become clearly marked custom exercises rather than silently dropping data.
- Unit changes only affect presentation; stored load remains canonical kilograms.
