# ACRPS Offline Podcast Engine

محرك محلي لتحسين التسجيلات الطويلة وتحويلها إلى نسخة بودكاست مع الحفاظ على الكلمات والتنفس والتوقيت وهوية المتحدث.

## البنية
- `web/`: واجهة HTML/CSS/JS فقط.
- `app/`: خادم محلي FastAPI وطابور المهام.
- `engine/`: خط المعالجة الصوتية، تكامل DeepFilterNet3، القياس والماستر.
- `config/`: إعدادات قابلة للتعديل.
- `scripts/`: تشغيل وإعداد Windows.
- `tests/`: اختبارات بنيوية وصوتية.

## التشغيل السريع على Windows
1. ثبّت Python 3.11 وFFmpeg واجعله في PATH.
2. شغّل `scripts/setup_windows.bat` مرة واحدة.
3. شغّل `scripts/start_windows.bat`.
4. افتح `http://127.0.0.1:8765`.

## ملاحظات مهمة
- المعالجة تتم محليًا بالكامل بعد التثبيت الأول.
- DeepFilterNet3 يُستخدم عند توفر الحزمة والنموذج المحلي. لا يوجد ادعاء زائف بوجود نموذج مضمّن داخل ZIP.
- عند عدم توفر النموذج، يرفض وضع `neural_required` التشغيل بدل الانتقال الصامت إلى معالجة سطحية.
- الإخراج الأساسي WAV 24-bit/48 kHz مع نسخة MP3 اختيارية.
